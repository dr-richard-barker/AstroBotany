# AstroBotany

A focused hub of plant space-biology projects — a curated subset of the
[COSE project family](https://dr-richard-barker.github.io/CoSE_Cloud/Hub/).

**→ https://dr-richard-barker.github.io/AstroBotany/**

The project grid is generated from the shared COSE registry (`sites.js`), so
descriptions, links and thumbnails stay in sync automatically.
